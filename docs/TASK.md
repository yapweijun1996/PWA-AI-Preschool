## Execution rules

Dependencies are hard release dependencies, not approval to deploy. Current integration command results are recorded in [CHANGELOG](CHANGELOG.md); source inspection and tests do not replace hosted/device/provider acceptance. Never use real data in this public checkout. Private real-data work requires a separate private service and governance clearance first.

Execution status: **D1 DONE** (this standard-set sync); **D2 PARTIAL** (local automated gates recorded, human content/print review remains separate); **D3 BLOCKED** (current hosted/device/provider acceptance absent); **N1 PLANNED** (requirements/measurement review not obtained); **P1 BLOCKED** (governance/vendor prerequisites absent); **P2–P7 BLOCKED** (private-service and predecessor gates absent); **R1 BLOCKED** (no accepted private pilot).

## Evidence limits and contradictions to resolve

- `docs/01-vision.md:5` supplies a six-hour / 150-student illustration. It is an unmeasured hypothesis, not an agreed baseline. Use only a measured cohort for savings or ROI claims.
- `src/studio/pages/about.js:7` says “Server, database or object storage” is not implemented. Interpret this as the portfolio application backend: optional remote Gateway transport exists in `src/providers.js:91-97`; it is not private school storage.
- `src/providers.js:8,101` selects `gpt-5-mini` for direct BYOK by default. The separately inspected Gateway configuration supplied on 2026-10-17 uses router OFF and OpenAI `gpt-5.4-mini`. These are different routes, not interchangeable runtime/model evidence.
- `src/providers.js:118-124` tests Gateway session issuance only. A “Connected” result cannot prove successful model generation, upstream quality or production privacy.
- Local name history persists in `src/portfolio-store.js:98-99`; keys and rejection reasons do not. Avoid broad “all identifiers are ephemeral” claims.
- Masking, `store:false`, absence of prompt/response schema columns and declared no-content logging do not establish upstream retention/training/location or actual proxy/runtime log practices.
